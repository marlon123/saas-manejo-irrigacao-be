# Architecture Decision Records

Registro das principais decisões arquiteturais do irrigation-management-backend. Cada ADR descreve o contexto, a decisão, as alternativas consideradas e as consequências. Uma decisão revista ganha um ADR novo, que substitui o anterior; o antigo é mantido com o status "Substituído".

| ADR | Título | Status |
|---|---|---|
| [ADR-001](ADR-001-separacao-two-model.md) | Separação two-model (domínio vs persistência) | Aceito |
| [ADR-002](ADR-002-strategy-registry-motor-de-calculo.md) | Strategy + Registry para o motor de cálculo | Aceito |
| [ADR-003](ADR-003-monolito-modular.md) | Monólito modular em vez de microsserviços | Aceito |
| [ADR-004](ADR-004-problem-details-rfc-7807.md) | Problem Details (RFC 7807) para erros | Aceito |
| [ADR-005](ADR-005-testes-baseados-em-propriedades.md) | Testes baseados em propriedades com jqwik | Aceito |

Modelo usado: Título, Status, Data, Contexto, Decisão, Alternativas consideradas e Consequências.
